Nexus Launcher (portable build)
==============================

Nexus Launcher is a native desktop launcher for the Straconis tool suite.
It reads catalog/apps.toml beside this program, looks up each tool's latest
public GitHub release, installs a build under your user account, and starts
it from a dark card grid.

Linux
  ./nexus-launcher
  ./nexus-launcher --check

Windows
  nexus-launcher.exe
  nexus-launcher.exe --check

Keep catalog/apps.toml next to the executable. Add another [[app]] table in
that file and press REFRESH. You do not recompile the launcher to add a tool.

This alpha has no system tray and no launch-at-login. MSI, deb, DMG, and
setup executables are downloaded and handed to the operating system; the
launcher does not run them silently and does not know whether installation
finished. Cards depend on each repository publishing a compatible release build.

--check parses the catalog and does not open a window or call GitHub.
There is no macOS binary in the v0.1.0-alpha release. Build from source
with Rust 1.99.1 if you need another platform. See README.md.

Windows installer
  The setup EXE adds Start > Straconis Software >
  Straconis Software Dev Nexus Launcher, without an administrator prompt.
  Reinstall/uninstall preserve an edited catalog and user data.

Central administration
  Configure a separately running broker using server_url in central.toml.
  No server credentials or developer VM address are bundled.

Window appearance
  The window opens maximized. Use Preferences in the account toolbar to
  compare charcoal header/footer colors with the original dark appearance.

The LAUNCHER strip can download a newer Nexus Launcher release and replace
this executable. It does not replace catalog/apps.toml or tools you already
installed. The published v0.1.0-alpha and v0.3.0-alpha downloads do not include that strip. If you are running one
of those files, install the first updater-enabled release by hand.
After that, the window can update itself.
